## ✨ Features

- 🔒 **BYOK Model** — Bring Your Own API Keys, encrypted in your browser
- 🤖 **12+ AI Providers** — Groq, Gemini, OpenRouter, xAI, DeepSeek, NVIDIA & more
- 🔍 **Auto-Detect** — Paste any API key → provider + URL auto-configured
- 💬 **Smart Chat** — Language-aware responses, regenerate with context cleanup
- 🎨 **Beautiful UI** — Dark/Light themes, smooth animations, custom scrollbar
- ⌨️ **Command Palette** — `Ctrl+K` for quick navigation (VS Code style)
- 📱 **Responsive** — Works on desktop, tablet, and mobile
- 🛡️ **Bank-Grade Security** — AES-GCM 256-bit, PBKDF2 600K iterations, CSP headers

## 🚀 Quick Start

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/asuum-universe.git
cd asuum-universe

# Install dependencies
npm install

# Start development server
npm run dev
